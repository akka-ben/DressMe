Objectif
--------
Remplacer le mock auth du backend FastAPI par une authentification reelle:
- inscription email
- verification email
- login email/password
- reset password par email
- login telephone par OTP
- JWT stateless
- endpoint current user /auth/me

Fonctionnalites implementees
----------------------------

1. Registration email
   - first_name, last_name, email, password.
   - Email unique.
   - Password min 8 caracteres.
   - Password hash avec bcrypt.
   - Compte cree avec is_verified=false.
   - Token de verification securise.
   - Token stocke en hash SHA-256 en base.
   - Email de verification envoye via SMTP.

2. Login email/password
   - Validation credentials.
   - Refus si email/password invalide.
   - Refus si email non verifie.
   - Retour JWT access_token.

3. Verification email
   - Endpoint GET et POST.
   - Token expire configurable.
   - Activation du compte.
   - Nettoyage du token apres usage.

4. Forgot/reset password
   - Forgot password ne revele pas si l'email existe.
   - Token reset securise.
   - Token reset stocke en hash SHA-256.
   - Expiration configurable.
   - Nouveau password hash avec bcrypt.
   - Nettoyage du token apres reset.

5. OTP telephone
   - phone_number unique.
   - Creation utilisateur telephone si necessaire.
   - OTP numerique.
   - OTP expire apres 5 minutes par defaut.
   - OTP stocke hashe avec bcrypt.
   - Verification OTP.
   - Retour JWT apres verification.

6. JWT security
   - Secret depuis BACKEND_SECRET_KEY ou JWT_SECRET_KEY.
   - Algorithm configurable.
   - Expiration configurable.
   - Dependency get_current_user.

7. Current user
   - GET /api/v1/auth/me.
   - Lecture du Bearer token.
   - Retour du profil utilisateur courant.

Commandes de lancement
----------------------

Depuis la racine du projet:

docker compose -f infra/docker-compose.yml up --build

Ou en local:

python3 -m venv .venv
source .venv/bin/activate
pip install -e ./backend
uvicorn app.main:app --reload --app-dir backend


Notes
-----
- Pour recevoir les emails en dev, utiliser Mailpit/MailHog sur localhost:1025
  ou configurer Mailtrap/Gmail dans .env.
- Le SMS est volontairement mock pour le moment, mais le service est isole pour
  pouvoir brancher Twilio sans toucher au router.
- Les changements faits auparavant dans le mauvais dossier n'ont pas ete supprimes.
