Objectif de cette section
-------------------------
Connecter le frontend mobile React Native / Expo a la vraie authentification

Flux final implemente
---------------------

1. L'utilisateur ouvre l'app.
2. AuthContext cherche un token dans AsyncStorage.
3. Si token trouve:
   - appel GET /auth/me avec Bearer token
   - si valide, l'utilisateur arrive directement sur le Feed
   - si invalide, token supprime et retour auth flow
4. Si aucun token:
   - affichage onboarding/login
5. Login:
   - POST /auth/login
   - recuperation access_token
   - GET /auth/me
   - stockage token
   - navigation Feed
6. Register:
   - POST /auth/register
   - message demandant de verifier l'email
   - retour possible vers login
7. Logout:
   - suppression du token
   - retour au flow non authentifie
8. Forgot password:
   - demande de reset via email
   - reception du lien /reset-password?token=...
   - ouverture directe de l'ecran Reset Password
   - changement du mot de passe via /auth/reset-password


Configuration importante
------------------------
Ne pas utiliser localhost sur telephone physique.

Utiliser l'IP locale de la machine backend:

EXPO_PUBLIC_API_URL=http://192.168.0.197:8000/api/v1

Si l'IP change, mettre a jour:
- mobile/.env
ou
- mobile/.env.example
ou lancer Expo avec la variable EXPO_PUBLIC_API_URL correcte.
