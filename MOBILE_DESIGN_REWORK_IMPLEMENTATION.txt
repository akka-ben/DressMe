DressMe_Chat - Phase Design Frontend Mobile
===========================================

Projet cible
------------
/Users/mohammedbenakkaouayad/Desktop/MASTER_WISD/S2/Web Mobile/DressMe_Chat


Objectif
--------
Refondre le design mobile DressMe selon une direction premium fashion:
- palette burgundy / creme / or
- ambiance editorial magazine
- navigation bottom tab 5 onglets
- feed social type Instagram
- messagerie type WhatsApp
- assistant IA stylist
- profil, recherche, creation de post, notifications, stories

L'architecture globale du projet n'a pas ete remplacee:
- App.tsx reste le shell principal
- les screens existants restent dans mobile/src/screens
- l'auth backend existante est conservee
- les donnees fashion sont mockees cote frontend pour la demo design


Dependances ajoutees
--------------------

1. lucide-react-native
   - Icônes modernes pour navigation, actions, messages, IA, notifications.

2. expo-linear-gradient
   - Degrades creme/burgundy.
   - Story rings.
   - Overlays story viewer.
