PostDetailScreen - Implementation reelle - 2026-05-03
=====================================================

Objectif
--------
Remplacer l'ancien PostDetailScreen mock par un vrai ecran detail de publication,
avec un comportement proche d'Instagram:

- ouvrir un post depuis le feed
- voir l'image/video, auteur, caption, hashtags, tags vetements
- liker/unliker
- sauvegarder/desauvegarder
- afficher les commentaires reels
- ajouter un commentaire
- synchroniser le tout avec FastAPI + MongoDB

Fonctionnement sauvegarde video
-------------------------------
Quand un post a:

media_type: "video"

ou un champ video_url / videos / media type video,
le backend detecte le post comme video.

Si l'utilisateur touche bookmark dans PostDetailScreen:

POST /api/v1/posts/{post_id}/save

Le document est ajoute dans saved_posts avec:

media_type: "video"

Ensuite il apparait dans le profil via:

GET /api/v1/users/me/saved-posts?media_type=video
